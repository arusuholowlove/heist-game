Velvet Vault — a top-down heist game you play in the browser. The Marlow Gallery closes at midnight: steal the Jade Mask, the Crimson Portrait and the Star Diamond, slip past three patrolling guards with visible vision cones and two sweeping security cameras, hide behind the display cases, and reach the service door before the alarm hits 100% or dawn breaks. A smoke bomb (Q, ×2) blinds every watcher for a few seconds, and a thrown coin (click, ×3) pulls a guard off its route to investigate the noise. Running is faster but loud — guards hear it. WASD or arrows to move, Shift to run, P to pause.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: everything is static files under `game/`.
